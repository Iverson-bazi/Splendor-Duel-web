# 宝石工坊：双人对决

一款受经典宝石收集桌游机制启发的本地双人网页版原型。当前版本包含公共宝石盘、三级卡牌市场、购买与保留、永久折扣、特权、王室卡、卡牌能力和三种即时胜利条件。

## 运行

直接双击 `index.html` 即可开始游戏，不需要安装或启动任何服务。

开发时也可以选择启动本地服务器：

```bash
npm start
```

如果 PowerShell 阻止执行 `npm.ps1`，可直接运行 `node server.js`，然后访问终端显示的本地地址。

## 测试

```bash
npm test
```

## 当前范围

- 同一设备上的双人轮流对战
- 原创占位美术与程序化卡牌数据
- 响应式桌面/移动界面
- 纯前端规则引擎，便于后续接入服务端联机

后续版本可加入房间系统、断线重连、行动计时、更多规则测试与正式卡牌平衡。
